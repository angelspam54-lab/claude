## The math (verified)

| | value |
|---|---|
| doublings | 63 (square 1 = 1 grain, square 64 = 2^63) |
| whole board | 2^64 − 1 = **18,446,744,073,709,551,615** grains (~18 quintillion) |
| first 32 squares | 2^32 − 1 = **4,294,967,295** (~4 billion) |
| square 64 alone | 2^63 = 9.22 quintillion, which is MORE than squares 1–63 combined (2^63 − 1) ✅ |
| mass | 0.045–0.065 g per wheat grain → 0.83–1.2 trillion tonnes |
| vs world wheat | ~790 Mt/yr → **1,050–1,520 years** → narrated as "more than a thousand years" ✅ |
| half board mass | 193–279 t → "a couple hundred tonnes" ✅ |
